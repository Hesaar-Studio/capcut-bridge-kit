# Explainer Captions Preset Style

Centered explainer aesthetic with high-contrast text backing.

## Visual Specs
- **Font**: Coolvetica / Plus Jakarta Sans
- **Placement**: Centered horizontal, vertical `y: -0.35`
- **Box Background**: Solid `#000000` with 8px corner radius
- **Text Color**: `#FFFFFF`
- **Padding**: Vertical 6px, Horizontal 12px
- **Tracking**: Tight (-0.02em)
